# 路线 C 论文骨架：动态秩分配的适用边界与"信号可预测性"判据

> 用途：确定叙事再决断是否成文。核心是把"负结果"转成**有正面贡献的判据 + 统一视角**。

---

## 0. 一句话论点（thesis）

> 在**预算严格对齐**下，LoRA 的动态秩分配（在线 goodput / 一次性 GoRA / SVD 剪枝 AdaLoRA）相对**静态均匀**在饱和（DeBERTa/GLUE）与非饱和（LLaMA/commonsense·gsm8k）两种 regime 下**均无稳健收益**；我们用"**分配信号的时间可预测性**"给出机制解释与操作性判据——动态分配有用当且仅当模块重要性信号**既有横截面 spread 又有时间可预测性**，而现有信号普遍缺后者。

这句话决定全篇：**卖点不是"我们做了个更好的分配器"，而是"我们给出何时该/不该做动态分配的判据"**。负结果因此变成可发表的边界刻画。

---

## 1. 叙事弧（story arc）

1. **直觉/现状**：秩分配是活跃方向（AdaLoRA/GoRA/…），共识是"重要模块给更多秩"。
2. **张力（gap）**：这些方法很少在①预算严格守恒、②强 baseline=uniform、③多 regime 下被干净对比。于是收益到底来自"分配"还是"额外容量/调参"存疑。
3. **受控研究设计**：把**分配时机**作为一根轴（静态均匀→一次性先验→在线动态→SVD 剪枝），预算严格守恒，跨 DeBERTa/GLUE 与 LLaMA/QLoRA 两模型族。
4. **发现（负结果）**：四方法在两 regime 均无稳健差异（GLUE 饱和持平；LLaMA excl-wino 75.0–76.8% 落在噪声内）。
5. **为什么（机制）**：提出双必要条件——(i) 横截面 spread、(ii) 时间可预测性。GLUE 缺 (i)（信号近均匀）；LLaMA 有 (i) 但缺 (ii)（E4：persist≈0、predict<0，"自信但错误"的重分配）。
6. **判据/工具**：signal-predictability 指标可在训练早期廉价计算，**事前预测"动态分配是否值得"**。
7. **收尾**：动态分配不是免费午餐；给出操作性判据 + 统一解释既有方法为何时灵时不灵。

## 2. 章节结构

- **Abstract**：论点 + 两 regime null + 判据。
- **1 Introduction**：动机、gap、贡献三点（受控对比框架 / 负结果 / 可预测性判据）。
- **2 Related Work**：AdaLoRA、GoRA/SaLoRA、DyLoRA、Pollux(goodput 起源)、LoRA 秩选择综述。定位：我们不提出新分配器，而是**审视分配这一步本身**。
- **3 A Controlled View of Rank Allocation**：把方法统一为"信号→分配时机→预算约束"三元组；定义预算守恒与 uniform 强 baseline。
- **4 Signal Predictability Diagnostic**：定义 spread（entropy/CV）、persistence（persist@lag）、predictiveness（predict@lag，信号 vs 未来 loss/goodput 增益的相关）。**这是核心方法贡献**。
- **5 Experiments**：DeBERTa/GLUE（8 任务）+ LLaMA/QLoRA（commonsense 7 子任务 excl-wino、gsm8k）；预算/参数/wall/rank-steps 全对齐。
- **6 Why No Gains: Diagnostic Analysis**：两 regime 分别落在双条件的哪一侧；winogrande 退化透明报告为 artifact。
- **7 When *Does* It Help?（positive control）**：构造信号可预测的场景，验证判据的另一半（**待补实验，见 §5 gap**）。
- **8 Conclusion / Limitations**：判据的适用范围与开放问题。

## 4. 必须补的实验（决定论文能否成立）

1. **多 seed（≥3）**：给 C1/C3 加置信区间——负结果论文的生死线。
2. **Positive control（C4，最关键）**：人为制造"信号可预测"的场景（如异质任务混合 / 部分层预冻结 / 秩需求刻意不均），证明**在该场景动态分配确实赢 uniform**。这把判据从"解释"升级为"可验证的双向预测"，是全篇最大加分项。
3. **强 baseline 对齐**：至少一个任务复现 AdaLoRA/GoRA 论文量级数字，堵"你没调好"。
4. **判据实用性 demo**：只用训练前 ~N step 的 predictability 指标，预测最终 gain 符号/大小。

## 5. 审稿风险与预案

- "负结果不 novel" → 强调**判据是正贡献** + 统一解释既有方法。
- "只有 goodput，可能实现/调参问题" → 覆盖 GoRA/AdaLoRA 两类他人方法也 null + 强 baseline 对齐 + 多 seed。
- "winogrande 剔除是 cherry-pick" → 透明报告 both（overall + excl-wino）+ 诊断证据。
- "两个模型两类任务够吗" → 定位为"存在性 + 机制"而非"普适 benchmark"，用判据泛化而非靠任务数堆量。

## 7. F1 展开（推荐框架的具体化）

**Intro 三段式**：
1. 秩分配方法层出不穷，共识"重要模块给更多秩"；但业界很少问"这一步到底值不值"。
2. 我们在预算严格对齐 + uniform 强 baseline 下做受控对比，发现两 regime 均无稳健收益——**问题不在具体分配器，而在信号本身**。
3. 我们给出一个**廉价、事前**的判据（signal predictability），能在训练早期预测"动态分配是否值得"，并解释既有方法为何时灵时不灵。

**Contributions（写进 intro 末尾的 bullet）**：
- **C-i 受控对比框架**：把秩分配拆成 `(信号, 时机, 预算约束)` 三元组，统一 uniform/GoRA/AdaLoRA/goodput，预算严格守恒。
- **C-ii 负结果**：两 regime（DeBERTa/GLUE 饱和、LLaMA/QLoRA 非饱和）动态分配均不优于 uniform（多 seed 置信区间）。
- **C-iii 可预测性判据**：定义 spread + temporal predictability 两必要条件；给出计算方法与**双向验证**（现有场景失败 + positive control 场景成功）。

**判据形式化（§4 core）**：对模块 m、训练步 t 的信号 \(s_m^{(t)}\)：
- spread：\(H(\bar s)/\log M\)（跨模块归一化熵），或 CV。
- persistence：\(\rho(s_m^{(t)}, s_m^{(t+\Delta)})\) 跨模块平均（信号自相关）。
- predictiveness：\(\rho(s_m^{(t)}, \text{未来增益}_m^{(t\to t+\Delta)})\)，未来增益用该模块参与的 loss 下降或有效秩增长代理。
- **判据**：动态分配有望获益 ⇔ spread 高 **且** predictiveness 显著 >0。现有信号：GLUE spread≈0；LLaMA predictiveness≈−0.18（反向）。

## 附录 A. Positive control 详细设计（C4，决定 F1/F3 成立与否）

**目的**：造一个信号**真的可预测**的场景，证明动态/先验分配显著 > uniform，从而验证判据的"正向半边"。缺它，F1/F3 只有"负向半边"，说服力大打折扣。

### A.1 主方案：植入式低秩恢复（synthetic planted low-rank）—— 便宜、干净、单卡分钟级

- 取一个冻结的小 base（DeBERTa-base 或 2–4 层 toy transformer）。
- 构造"教师"：在**已知子集**的模块上植入非零低秩 \(\Delta W^\*\)（如仅 layer 6–9 的 q/v proj，秩=4），其余模块 \(\Delta W^\*=0\)。教师 = base + 植入。
- 学生：LoRA（总预算与 uniform 对齐）蒸馏拟合教师输出（回归/KL）。
- **预期**：
  1. 拟合误差：GoRA/goodput ≪ uniform（uniform 把预算浪费在零目标模块）。
  2. 判据指标：persistence 高、predictiveness ≫0，spread 高。
  3. 分配收敛到植入 support（可视化 rank map vs ground-truth support）。
- **可控旋钮**：植入 support 的稀疏度、秩、层位置——扫一遍得到"判据值 vs 动态分配增益"的**单调曲线**（这张图就是 C-iii 的核心证据）。

### A.2 拉伸方案：相位异质任务（验证"在线 > 一次性"这根时机轴）

- 训练分两相，相位 1 让 A 组模块重要、相位 2 让 B 组重要（如两类数据/两目标交替）。
- 只有**在线动态**能随相位迁移预算；一次性 GoRA 锁死在相位 1 的估计、uniform 全程平均。
- **预期**：online goodput > GoRA > uniform，且 predictiveness 在相位边界处高。这条专门支撑"分配时机"轴的价值，是 goodput（在线）唯一可能真正赢的场景。

### A.3 落地成本

- A.1：单卡（9 号）、小模型、分钟到十分钟级，先做，用来出"判据 vs 增益"主图。
- A.2：中等成本，若 A.1 成立再做，作为"在线优势存在性"的加分。
- 两者都**不依赖 LLaMA**，与正在跑的多 seed 互不抢卡。
